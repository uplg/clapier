Window

Type fenêtre.
Il peut s'agir d'une fenêtre mère, d'une fenêtre fille ou d'une fenêtre popup.
Le cycle de vie d'une fenêtre est :
  • création : par exemple avec windowCreate
  • destruction : avec windowDestroy ou par l'utilisateur lui-même
  • oubli : perte de la référence par le programme
