tagSub = fun [
Tag _tag_
]list Xml

NOM DE CHAMP DE LA STRUCTURE Tag.

Paramètres
_tag_
N'importe quel tag.
Valeur de retour
Retourne le champ contenant la liste des sous-noeuds d'un Tag.
Remarque
On écrira, comme pour tout champ de structure :
  • x.tagSub : pour extraire la liste de sous-noeuds d'un tag 'x'
  • [tagSub:l] : pour construire un tag dont la liste de sous-noeuds est 'l'
