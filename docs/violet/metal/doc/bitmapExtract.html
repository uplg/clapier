bitmapExtract = fun [
B _dst_
Bitmap _bitmap_
I _comp_
]B

Extrait les valeurs d'une des composantes de l'image et les stocke dans le buffer. Le stockage est fait par ligne, de haut en bas, et pour chaque ligne de gauche à droite.

Paramètres
_dst_
Un buffer quelconque.
_bitmap_
N'importe quelle bitmap dont le nombre de pixels est exactement égal à la taille du buffer _dst_.
_comp_
Numéro de composante (0 : rouge, 1 : vert, 2 : bleu)
Valeur de retour
Le buffer passé en paramètre.
