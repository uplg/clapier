bitmapToTab = fun [
Bitmap _bitmap_
]tab I

Retourne le contenu d'un bitmap dans un tableau de valeurs RGB.

Paramètres
_bitmap_
N'importe quelle bitmap.
Valeur de retour
Une table d'entiers contenant les valeurs RGB du bitmap, dans l'ordre classique du balayage de l'écran : de gauche à droite, puis de haut en bas.
