gethostname = fun [
]S

Fonction 'hostname' classique.

Valeur de retour
Retourne le nom de la machine locale.
Remarque
Si le nom ne peut être déterminé, la fonction retourne la chaîne 'localhost'
L'utilisation 'gethostbyname gethostname' permet de récupérer la liste des adresses 'ip' locales.
