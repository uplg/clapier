mp3Process = fun [
MP3 _mp3_
S _src_
I _index_
I _len_
]S

Décode des données mp3.

Paramètres
_mp3_
Décodeur mp3
_src_
Source des données mp3 à décoder
_index_
Index des données dans la source
_len_
Taille des données dans la source (nil : toutes les données à partir de l'index)
Valeur de retour
Les données décodées. nil si pas assez de sources.
Remarque
La taille des données à fournir semble poser des problèmes dans certains cas, notamment lorsque le fichier mp3 complet est transmis en une seule fois. Il est recommandé de conserver une taille faible, de l'ordre de 64ko.
