Bitmap

Type bitmap.
Il s'agit d'une zone graphique rectangulaire, dont chaque pixel est associé à une couleur RGB 24 bits. Par exemple 0xff0000 correspond à la couleur rouge vif.
Le cycle de vie d'une bitmap est :
  • création : par exemple avec bitmapCreate
  • destruction éventuelle : avec bitmapDestroy, ce qui libère les ressources graphiques correspondantes
  • oubli : perte de la référence par le programme (l'oubli d'une bitmap non détruite entraîne sa destruction et libère donc les ressources graphiques correspondantes)
