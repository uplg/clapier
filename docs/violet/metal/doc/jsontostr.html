jsontostr = fun [
Json _src_
]S

Génère la chaîne au format Json correspondant à l'élément Json passé en paramètre.

Paramètres
_src_
Elément Json à sérialiser.
Valeur de retour
Encodage de l'élément Json.
Remarque
La chaîne générée n'a aucune mise en page, et notamment aucun retour à la ligne. On utilisera la fonction jsonstring pour recréer complètement la fonction jsontostr en Metal.
