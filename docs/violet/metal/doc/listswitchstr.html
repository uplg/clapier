listswitchstr = fun [
list [S u0] _list_
S _pattern_
]u0

Recherche d'une valeur associée à un mot.

Paramètres
_list_
Une liste de tuples de deux éléments : une chaîne et un type quelconque.
_pattern_
Une chaîne quelconque.
Valeur de retour
Recherche si le 'pattern' est le premier mot (avec casse respectée) d'un des tuples. Si oui, retourne la seconde valeur du tuple.
Remarque
Par exemple : (listswitchstr ["x" 123]::["y" 456]::nil "x") -> 123
