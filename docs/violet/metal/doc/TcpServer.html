TcpServer

Type serveur Tcp.
Un serveur Tcp permet à la machine d'être à l'écoute de connexions de correspondants. Lorsqu'une telle connexion a lieu, une connexion Tcp est créée.
Le cycle de vie d'un serveur Tcp est :
  • création : avec tcpserverCreate
  • destruction : avec tcpserverDestroy
  • oubli : perte de la référence par le programme
