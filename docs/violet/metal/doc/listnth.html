listnth = fun [
list u0 _list_
I _index_
]u0

Calcule le n-ieme élément d'une liste.

Paramètres
_list_
Une liste quelconque.
_index_
Un entier quelconque.
Valeur de retour
Retourne le n-ieme élément d'une liste. Le premier élément a pour index '0'.
Remarque
listnth l 0 == hd l
la fonction retourne nil si l'index ne correspond à aucun élément : index négatif ou supérieur au nombre d'éléments de la liste
