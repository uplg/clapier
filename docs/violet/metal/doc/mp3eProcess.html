mp3eProcess = fun [
MP3e _mp3e_
S _src_
I _index_
I _len_
]S

Encode des données wav en mp3

Paramètres
_mp3e_
Encodeur mp3
_src_
Source des données wav à encoder
_index_
Index des données dans la source
_len_
Taille des données dans la source (nil : toutes les données à partir de l'index)
Valeur de retour
Les données encodées.
