Tcp

Type connexion Tcp.
Une connexion Tcp est une liaison réseau logique entre deux entités. La connexion a lieu à l'initiative d'un des correspondants, qui contacte un serveur Tcp de l'autre correspondant. Une fois la connexion établie, celle-ci devient symétrique, et chacun peut décider de la fermer.
Le cycle de vie d'une connexion Tcp est :
  • création : soit avec tcpOpen pour l'appelant, soit dans la callback du serveur Tcp définie dans tcpserverCreate
  • destruction : avec tcpClose
  • oubli : perte de la référence par le programme
