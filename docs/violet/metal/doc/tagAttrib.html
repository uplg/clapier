tagAttrib = fun [
Tag _tag_
]list [S S]

NOM DE CHAMP DE LA STRUCTURE Tag.

Paramètres
_tag_
N'importe quel tag.
Valeur de retour
Retourne la liste de attribut d'un Tag, sous la forme d'une liste de tuples [nom_attribut valeur_attribut].
Remarque
On écrira, comme pour tout champ de structure :
  • x.tagAttrib : pour extraire la liste d'attributs d'un tag 'x'
  • [tagAttrib:l] : pour construire un tag dont la liste d'attributs est 'l'
