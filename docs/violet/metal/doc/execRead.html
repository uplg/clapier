execRead = fun [
Exec _exec_
]S

Lit sur la sortie standard de l'exécutable.

Paramètres
_exec_
Un exécutable quelconque.
Valeur de retour
Une chaîne de caractères.
Remarque
Cette fonction est bloquante : elle ne retourne nil que si l'exécutable a fermé sa sortie standard (ce qui signifie généralement qu'il a terminé)
