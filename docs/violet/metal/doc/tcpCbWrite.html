tcpCbWrite = fun [
Tcp _connection_
fun [Tcp] I _callback_
]Tcp

Définit la callback de la connexion Tcp sur l'événement 'write'.

Paramètres
_connection_
Une connexion Tcp.
_callback_
Une callback.
Valeur de retour
La connexion Tcp passée en paramètre.
Remarque
Cet événement se produit :
  • initialement pour indiquer que la connexion est établie, et donc qu'il est possible d'émettre des données
  • après un appel à tcpSend qui n'a pas accepté toutes les données que l'on souhaitait émettre, lorsque la connexion est de nouveau prête à émettre de nouvelles données.

La callback peut parfaitement faire toute sorte d'opérations sur la connexion, y compris la fermer.
