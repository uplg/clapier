append = fun [
S _content_
S _file_
]I

Concatène une chaîne de caractère à la fin d'un fichier.

Paramètres
_content_
Une chaîne de caractères quelconque.
_file_
Un nom de fichier éventuellement relatif.
Valeur de retour
Retourne 0 si succès, -1 si erreur, nil si un des paramètres valait nil.
Remarque
Si le fichier n'existait pas, il est créé, et son contenu est initialisé avec la valeur _content_
