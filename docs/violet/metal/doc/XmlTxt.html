XmlTxt = fun [
S _text_
]Xml

CONSTRUCTEUR DE TYPE SOMME.

Paramètres
_text_
Une chaîne quelconque.
Valeur de retour
Un objet Xml Texte contenant le texte passé en paramètre.
Remarque
On écrira, comme pour tout constructeur de type somme :
  • XmlTxt txt : pour construire un type Xml contenant le texte 'txt'
  • (match x -> (XmlTxt txt-> ...expr...)) : pour extraire et traiter le texte 'txt' d'un type Xml
