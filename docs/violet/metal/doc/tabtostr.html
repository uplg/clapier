tabtostr = fun [
tab I _table_
]S

Conversion d'un tableau de codes ascii en une chaîne.

Paramètres
_table_
N'importe quelle table d'entiers.
Valeur de retour
Retourne la chaîne constitué des caractères dont les codes ascii sont les éléments de la table passée en paramètre.
