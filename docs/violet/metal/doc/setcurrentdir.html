setcurrentdir = fun [
S _dir_
]I

Réglage du répertoire courant de la machine virtuelle.

Paramètres
_dir_
Un nom de répertoire logique, éventuellement relatif.
Valeur de retour
Retourne 0 si succès, -1 si erreur, nil si le paramètre valait nil.
Remarque
On rappellet qu'un nom de répertoire logique se termine toujours par le caractère '/'
