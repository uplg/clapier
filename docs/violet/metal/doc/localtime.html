localtime = fun [
I _time_
][I I I I I I I I]

Décode l'heure locale.

Paramètres
_time_
Temps en secondes depuis 01/01/1970.
Valeur de retour
Tuple [secondes minutes heures jour_du_mois mois annee jour_de_la_semaine jour_de_l_annee].
Remarque
Les mois sont numérotés à partir de 0 (janvier), les jours de la semaine sont numérotés à partir de 0 (lundi).
