filesign = fun [
S _file_
]S

Calcul de la signature d'un fichier.

Paramètres
_file_
Un nom de fichier éventuellement relatif.
Valeur de retour
Retourne une chaîne de 16 caractère contenant une signature du contenu du fichier passé en paramètre. Retourne nil si impossible de lire fichier.
