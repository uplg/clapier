bitmapFromFile = fun [
S _file_
]Bitmap

Lit un fichier graphique et crée une bitmap correspondant à son contenu.

Paramètres
_file_
Le nom d'un fichier contenant une image dont le format est reconnu. Ce nom est soit complet, soit relatif.
Valeur de retour
Nouvelle bitmap contenant l'image. Vaut nil, si erreur (fichier inexistant ou ne correspondant pas à un format reconnu).
Remarque
Les formats reconnus sont :
  • BMP monochrome
  • BMP 8 bits paletté
  • BMP 24 bits
  • GIF (dans le cas d'un gif animé, seule la première image sera prise en compte ; voir bitmapFromGif pour une gestion complète des gif animés)
  • JPEG
  • PNG
