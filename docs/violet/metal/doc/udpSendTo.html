udpSendTo = fun [
Udp _udp_
S _content_
S _dst_
]I

Envoie un message sur une socket Udp.

Paramètres
_udp_
Socket Udp
_content_
Message à transmettre.
_dst_
Adresse du destinataire, sous la forme "ip:port"
Valeur de retour
0 en cas de succès.
