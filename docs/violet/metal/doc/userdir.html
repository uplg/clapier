userdir = fun [
]S

Retourne le chemin d'un répertoire dans lequel l'application peut stocker des fichiers personnels, par exemple l'état de l'application.

Valeur de retour
Le chemin d'un répertoire de travail pour l'application.
Remarque
La fonction retourne la chaîne vide sur Win/Linux/Mac, mais pas sur iOS et Android
