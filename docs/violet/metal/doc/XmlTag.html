XmlTag = fun [
Tag
]Xml

CONSTRUCTEUR DE TYPE SOMME.

Paramètres
Un Tag quelconque.
Valeur de retour
Un objet Xml Tag contenant le tag passé en paramètre.
Remarque
On écrira, comme pour tout constructeur de type somme :
  • XmlTag t : pour construire un type Xml contenant le tag 't'
  • (match x -> (XmlTag t-> ...expr...)) : pour extraire et traiter le tag 't' d'un type Xml
