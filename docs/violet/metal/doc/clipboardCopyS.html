clipboardCopyS = fun [
S _copy_
]S

Copie une chaîne de caractères dans le clipboard. Cette chaîne pourra être copiée dans une application Métal (fonction clipboardPasteS) ou dans une autre application (généralement fonction "coller").

Paramètres
_copy_
Chaîne de caractères à "copier"
Valeur de retour
